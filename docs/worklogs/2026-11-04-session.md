# 2026-11-04 CampusRent 대화·작업 기록

9주차 Oracle DB 접속 안내와 연결 준비·검사 결과를 정리한다. 실제 서버 주소·계정·비밀번호는 이 문서에 포함하지 않는다. 파일 수정은 로컬 저장소에서 수행하며 사용자가 승인한 이번 Commit·Push는 로컬 Git으로 진행한다.

## 요청과 준비

- 사용자가 수업 안내에 따라 Java·Spring·드라이버 호환성 확인, 본인 팀 DB 연결, 비밀 설정의 Git 제외, ERD 기준 객체 생성·CRUD 검증을 요청했다.
- 다른 팀의 예시 계정은 사용하지 않았고 사용자가 확인한 본인 배정 계정만 사용했다.
- 실제 비밀번호는 Git에서 제외한 로컬 설정 파일에만 반영했다. 비밀번호의 구체적인 값이나 다른 정보와의 관계는 기록하지 않는다.
- Java 1.8.0_503·javac 1.8.0_151을 확인했다. 현재 저장소에는 Spring Boot 빌드·서버 진입점이 없어 별도 Java 8 JDBC 검사 도구를 준비했다.
- Oracle 공식 안내를 확인해 `com.oracle.database.jdbc:ojdbc6:11.2.0.4`를 선택하고 Maven Central 배포 체크섬을 대조했다.

## 로컬 변경

- `.gitignore`: 실제 application-local.properties·local YAML·.env 및 빌드 산출물 제외, 비밀 없는 예시는 추적 가능.
- `src/main/resources/application-local.properties.example`: 실제 접속 정보 없는 SID 연결 예시. 실제 local 파일은 미추적·Git 제외 상태를 확인했다.
- `tools/setup-oracle-jdbc.ps1`: 고정 HTTPS 배포 주소에서 드라이버·체크섬을 검증하고 `.work/jdbc/`에 저장.
- `tools/check-oracle-connection.ps1`, `tools/OracleConnectionCheck.java`: 설정 검증과 단일 계정 읽기 전용 접속 검사. URL·계정·비밀번호·원문 드라이버 예외를 출력하지 않음.
- `tools/run-oracle-schema.ps1`, `tools/OracleSchemaTool.java`: 검토한 고정 SQL 파일의 오프라인 파싱·본인 스키마 준비 확인·설치·검증·테스트. 설정·접속 정보는 출력하지 않음.
- `db/oracle11g/tests/crud.sql`: 생성한 고유 합성 행만 생성·조회·수정·삭제하고 자체 Savepoint로 롤백.
- [로컬 연결 안내](../../db/oracle11g/CONNECT.md)와 루트 README에 실행 방법·진행 상태를 반영.

접속 검사는 DUAL·세션 컨텍스트·본인 USER_TABLES·버전 정보에 한정했다. 이후 사용자의 이름 유지 선택을 확인하고 본인 스키마에만 설치했다. 사전 충돌 검사·권한 확인 뒤 00~04를 순서대로 실행했으며 기존 객체 삭제·다른 스키마 조회·자동 재시도는 하지 않았다.

무결성·CRUD는 각각 별도 연결에서 합성 데이터로 실행했고 성공 문구와 오류 부재를 확인했다. 테스트 데이터는 롤백했으며 시퀀스 번호만 일부 소모됐다. 애플리케이션의 중복 승인·누적 반환·권한 통합 시험은 이 DB 구축 단계에서는 수행하지 않았다. Git Commit·Push는 승인 대기 상태로 진행하지 않았다.

## 객체 이름과 남은 작업

기존 SQL의 ERD 테이블명은 APP_USER 등이고 시퀀스는 SQ_APP_USER 등이다. 수업의 TBL_·SEQ_ 규칙과 차이를 설명하고 확인을 요청했다. 사용자는 **기존 ERD·SQL 이름 유지**를 선택했다. 이름 변경 없이 기존 설치 SQL을 사용한다.

1. Spring Boot 버전·데이터 접근 방식을 확정하고 서버 DAO·인증·트랜잭션을 연결한다.
2. 실제 서버에서 동시 승인·반납 회차·누적 반환·역할/소유권을 통합 검증한다.
3. 확정한 초기 데이터와 운영 정책을 반영한다. 이미 생성된 스키마에 설치 스크립트를 반복 실행하거나 기존 데이터를 임의 삭제하지 않는다.
4. 사용자 승인 후 변경 파일에서 비밀값 제외를 재확인하고 로컬 Git으로 Commit·Push한다.

## 이어서 진행한 서버 연동

사용자의 다음 단계 진행·중지된 작업 재개 요청에 따라 로컬 서버와 화면을 Oracle에 연결했다. 기존 스키마 이름·DDL은 변경하지 않았으며 GitHub 브라우저 수정·Commit·Push는 진행하지 않았다.

- 전용 Temurin JDK 21.0.13·Maven 3.9.16을 공식 체크섬으로 검증하여 `.work/runtime`에 준비했다. 시스템 Java 8·전역 PATH는 유지했다.
- Spring Boot 4.1.2·Thymeleaf·JdbcTemplate·HikariCP·Security, 서버 JDBC `ojdbc8:19.33.0.0`을 구성했다. Java 8 단독 SQL 도구와 드라이버를 구분한다.
- 회원가입은 STUDENT만 생성하고 BCrypt로 비밀번호를 저장한다. 세션·CSRF·역할·소유권·항목/장비 버전을 서버에서 검사한다.
- 자원 조회, 신청·취소·반납 신청, 관리자 승인·거절·출고·보류·추가 반환·점검·시설 시작/종료를 Oracle에 저장한다. 승인 대기는 미확보, 자원 잠금 후 승인 중복 검사, 반환 회차의 이번 수량과 누적 수량, 조기 시설 종료의 원래 예약 기간을 유지한다.
- 가상 장비 7개·시설 5개와 관련 사양·구성품·운영 시간·대체 관계 및 로컬 앱 관리자 1명을 최초 준비했다. 실제 초기 관리자 값은 Git 제외 파일에만 저장하고 초기 준비 플래그는 false로 되돌렸다. 기존 데이터를 삭제하거나 DDL을 다시 실행하지 않았다.
- `store.js`를 실제 서버/독립 시연 어댑터로 나누고 기존 UI에 연결했다. 서버 장애 시 데모 데이터로 대체하지 않는다. 선택 목록만 sessionStorage에 저장한다.
- 실제 Oracle HTTP 통합 검증 20개 통과: CSRF·학생 역할 고정·소유권, 동시 승인 중 1건만 성공, 오래된 버전 차단, 출고 기준 저장, 반납 보류·초과/추가 반환·점검, 시설 실제 시간, 공개 조회의 개인정보 제외, 세션 종료·재로그인 후 영구 저장.
- 임시 Chrome 서버 화면 검증 20개 통과: 주요 화면 4개와 모바일·이미지, 일정 적용·선택, 실제 로그인·선택 유지·새로고침·개인 내역·로그아웃·브라우저 인증 정보 미저장.
- JUnit 업무 정책 테스트 7개와 기존 데이터 검사 15개 통과, 실행 JAR 패키징 성공. 실제 DB 조합의 동작 확인이며 모든 JDBC 조합의 공식 인증이나 외부 배포 검증을 의미하지 않는다.
- 이번 API 시험에서 만든 고유한 두 합성 학생 계정·신청·검수 관련 38행만 한정하여 정리했다. 초기 자원·관리자는 유지했으며 시퀀스·버전 번호는 되돌리지 않았다.
- 실행 방법·초기 계정 확인 위치·테스트·남은 범위는 `docs/SERVER.md`, 계획서는 v0.15로 갱신했다.

현재 개발 서버는 `http://127.0.0.1:8081`, 기존 독립 시연은 `preview.cmd`의 8080이다. 장비 관리(F08)·대체 관계 편집(F17 관리 부분)·시설 운영 관리(F21), 10/28 UI 개선, 학교 SSO·외부 배포는 후속 작업이다. 실제 접속 정보나 비밀번호를 공개 문서에 기록하지 않는다. 이 단계까지는 Git 공유를 보류했고, 아래 사용자의 승인 요청에 따라 로컬 Git 공유를 진행한다.

## 연결 상태 확인과 Git 공유 요청

- 사용자가 연결 중단 뒤 작업 진행 여부를 질문했다. 로컬 서버의 실제 catalog API에서 자원 12개 조회를 확인하고, 핵심 연동·테스트 작업을 마쳤으며 서버가 실행 중이라고 안내했다. 채팅 연결 종료 후에도 개발 작업이 계속 진행 중이라고 표현하지 않았다.
- 사용자가 지금까지의 대화·작업 기록을 GitHub에 Commit·Push하도록 승인했다. 대화의 결정·구현·검증 결과를 이 기록에 요약하며 실제 접속 정보·비밀번호는 포함하지 않는다.
- **각자의 VS Code 로컬 파일을 수정하고 로컬 Git으로 Commit·Push한다. GitHub에 직접 로그인하거나 브라우저에서 파일을 수정하지 않는다.** 이 원칙을 다시 확인했다.
- 공개 변경 후보와 패키지에서 실제 DB·앱 관리자 비밀값이 제외되고, 실제 local 설정은 Git 제외·미추적 상태인지 점검한 뒤 공유한다. 런타임·캐시·빌드·화면 캡처·합성 계정 정보는 포함하지 않는다.
