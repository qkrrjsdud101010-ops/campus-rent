## 문구와 디자인

60×85cm 세로형, 밝은 중립 배경 `#FAF8F3`, 맑은 고딕 계열, 외곽 여백과 3개 기능 영역을 유지했다. 파랑·청록·갈색 화면 프레임의 위치와 크기도 유지했다. 프로젝트명·부제·오른쪽 주요 문구·팀원 표기를 보존했다.

- 작은 상단 문구를 `문제 가설과 주요 구현 화면`으로 변경했다.
- 첫 기능 제목은 `문장 분석·목적별 추천`이다. 실제 호출 성공 근거를 확인하여 설명을 `GPT가 활동 문장을 분석해 인원과 준비 항목을 제안합니다.`로 시작한다.
- `활동 문장 분석 → 사용자 조건 확인 → DB·추천 규칙 조회 → 선택 및 신청` 흐름과 OpenAI API의 활동 문장 분석 역할을 명시했다. 시설 허용 목적·재고·가용성은 서버와 Oracle에서 확인한다.
- 대체 자원은 같은 일정, 다른 일정은 같은 자원을 기준으로 구분했다. 기존 화면설계서의 대체 시설·다른 이용 시간대 탭과 기간 변경 확인을 유지했다.
- 신청 상태 영역은 관리자 승인·거절과 진행 상태, 출고 당시 구성품, 반납 보류·추가 반환의 누락 재확인으로 설명했다. 화면 예시는 승인 대기와 구성품 검수 입력이며 실제 처리 완료 상태로 표현하지 않았다. 관리자 화면은 추가하지 않았다.
- 2026.11.12의 서로 다른 API·화면 검증 수치를 새 수치와 합산하지 않았다. 현재 Java 단위 테스트 97개 통과와 GPT 실제 호출 성공을 별도 성격의 기록으로 표시했다.

## 첫 영역의 실제 화면

2026-11-18, `http://127.0.0.1:8081/purpose`의 실제 Spring Boot·Oracle 개발 서버를 Chrome에서 열었다. 기존 사용자 탭의 작성 내용은 보존하고 캡처용 탭에서 진행했다. UI의 문장 분석을 한 번 실행하고 **AI 분석** 표시와 실제 제안을 관찰했다. 입력 문장은 `4명이 면접 연습을 하고 녹화하려고 해요`다.

실제 결과는 면접 연습·4명·영상 촬영 필요이며 공간은 필요 없음이었다. 사용자가 제안별 체크박스로 공간=false 적용을 해제하여 원래 공간=true를 유지하고, 활동명 제안을 선택한 뒤 **확인 후 추천에 적용**을 눌렀다. 이어서 추천 구성 보기를 실행해 공간·영상 촬영 조건의 시설 후보와 카메라 후보를 확인했다. 시설의 실제 허용 목적은 선택하지 않았으므로 시설은 정보 후보이며 신청이 확정되거나 허용된 상태가 아니다. 선택 목록은 0개였다.

브라우저의 실제 전체 페이지 캡처에서 입력 한 줄, 활동·인원과 공간/영상 제안, 확인 적용 버튼을 각각 사각형으로 발췌해 간격을 두고 배치했다. 작은 글씨를 더 줄이지 않기 위한 편집이며, 원래 화면의 값·문구·체크 상태를 합성하거나 다시 그리지 않았다. 포스터에 발췌임을 명시했고 전체 분석 영역 이미지도 함께 보관했다. 음성·자료 투사 항목은 기능에서 유지되며 확대 배치를 위해 포스터 발췌 영역에서는 생략했다.

시설·장비 이미지는 같은 캡처 세션에서 확인 적용 후 조회한 카드의 이름과 추천 이유 부분이다. 긴 관리번호를 중심에 두지 않았다. 캡처에는 가상 자원을 사용했으며 개인 계정 헤더·브라우저 UI·설정은 발췌 범위에서 제외했다.

## 재사용한 화면

두 번째·세 번째 영역은 2026년 10월 화면설계서 시연 이미지를 재사용했다. 출처는 기존 `New-Era 화면설계서_20261026.pptx`와 `New-Era 화면설계서_20261027.pdf`에서 추출한 U-007, C-005, U-008, A-007 화면이다. 각 프레임의 **화면설계서 시연 2026.10** 표기를 유지했다. 최신 GPT 실행 또는 현재 운영 DB의 처리 이력으로 설명하지 않았다.

## 검증과 남은 범위

- 실제 외부 API 검증 기록은 HTTP 200, source=ai, 약 2.734초다. 한 문장에 대한 연결 성공이며 모든 문장의 의미 해석 정확도를 검증한 것은 아니다. 실제 공간=false 제안을 설명용 공간=true 예시로 바꾸지 않았다.
- 2026-11-18의 최신 Surefire 보고서에서 Java 테스트 97개·실패 0·오류 0을 대조했다. 이번 포스터 작업 중 Java 테스트를 새로 실행하지는 않았다.
- PDF는 1쪽, 600×850mm다. SVG의 텍스트·도형은 편집 가능하고 화면 이미지 10개는 내장했다. PNG는 실제 PDF에서 3600×5100px로 렌더링했다.
- 텍스트 50행의 폭과 이미지 영역을 검사했다. 최종 PNG를 열어 전체 배치·줄바꿈·겹침·잘림·이미지 가독성을 확인했다. 기존 원본의 해시가 그대로임을 확인했다.
- 실제 키·개인정보·내부 설정은 포스터에 넣지 않았다. 예약 제출·DB 데이터 변경·커밋·푸시는 수행하지 않았다.
- 남은 범위는 두 번째·세 번째 영역의 최신 실행 화면 교체와 인쇄소 출력 조건 확인이다. 현재 재사용한 시연 이미지의 날짜는 포스터에 표시했다. 실제 학교 재고·운영 정책 및 다양한 문장의 분석 품질은 별도 검증 대상이다.
