# CampusRent

**이용 목적에 맞는 교내 시설·장비 추천 및 대여·예약 관리 시스템**

> 정보시스템프로젝트캡스톤디자인 | New-Era 팀  
> 분석·설계 문서를 기반으로 실제 시스템 구현을 준비하는 프로젝트입니다.

## 1. 프로젝트 소개

CampusRent는 학생이 필요한 교내 시설·장비를 **직접 검색**하거나, **활동 목적과 참여 인원 등에 맞는 추천**을 받아 적합한 자원을 선택하고 대여·예약을 신청할 수 있도록 지원하는 웹 기반 정보시스템입니다. 관리자는 신청 승인·거절, 장비 출고·반납, 시설 이용 상태 등을 관리합니다.

**핵심 차별점은 목적 기반 탐색입니다.** 예를 들어 학생이 '학생회 회의 6명' 또는 '과제 영상 촬영'을 입력하면, 등록된 용도·키워드·인원 조건에 따라 적합한 공간과 장비, 추천 이유를 안내합니다. 필요한 자원을 이미 알고 있다면 이름이나 분류로 직접 검색할 수도 있습니다.

> 목적별 추천은 현재 계획서상 **규칙 기반**이며 별도의 AI 추천 모델을 사용하지 않습니다. 실제 학교 자원 및 운영 정책은 확인이 필요한 부분이 있고, 현재 시연 데이터에는 가상 시설·장비가 포함됩니다.

## 2. 프로젝트 목표

- 이용 목적과 인원에 맞는 시설·장비를 추천하고 추천 이유를 제시
- 시설·장비 직접 검색, 상세 정보 및 이용 조건 확인 지원
- 이용 불가 시 다른 일정 또는 대체 시설·장비 조회 지원
- 선택 목록에서 필요한 항목과 조건을 확인한 뒤 개별 신청
- 관리자 승인·거절, 장비 출고·반납·점검 및 시설 이용 이력 관리

## 3. 핵심 기능

| 구분 | 주요 기능 | 관련 기능 ID |
| --- | --- | --- |
| **목적별 추천** | 활동 내용·참여 인원·용도에 따라 시설·장비와 추천 이유 안내 | F27 |
| **직접 검색** | 시설·장비 목록 검색, 사양·구성품·수용 인원·이용 조건 확인 | F02·F03·F19 |
| **선택 목록** | 추천·검색 결과를 담고 항목별 일정과 조건을 확인한 뒤 신청 | F28 |
| **대체 조회** | 동일 자원의 다른 일정 또는 같은 일정의 대체 자원 탐색 | F16·F17·F25 |
| 대여·예약 신청 | 장비 대여 및 시설 예약 신청, 승인 전 취소 | F04·F05·F20 |
| 관리자 처리 | 승인·거절, 출고 검수, 반납·보류·추가 반환, 시설 이용 처리 | F09·F10·F12·F22·F23·F29 |
| 현황·이력 | 학생 신청 현황과 과거 내역, 관리자 처리 이력 조회 | F06·F11·F24 |

**서비스 흐름:** 목적 입력 또는 직접 검색 → 추천·조회 결과 확인 → 선택 목록 → 조건 확인 및 신청 → 관리자 승인·이용·반납 처리

※ 추천·선택·로그인만으로 예약이 확정되지 않습니다. 승인 대기는 자원 확보 상태가 아니며, 관리자 승인 시 조건을 재확인합니다.
