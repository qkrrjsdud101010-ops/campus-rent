# CampusRent 포스터용 화면 이미지

## 사용하는 파일

- `01_포스터_핵심화면`에 포스터 후보 12개가 있습니다.
- `02_보조화면`에 나머지 원본 25개가 있습니다.
- `03_나란히_배치한_화면`에는 추천 결과와 검수 화면의 원본 영역 두 개씩을 여백을 두고 배치한 PNG 4개가 있습니다. 각 영역의 원래 픽셀 크기를 유지했습니다.
- `00_핵심화면_미리보기.png`에서 후보를 한눈에 고를 수 있습니다.
- `화면_추출목록.csv`에는 화면 ID, 설계서 쪽수, 원본 크기, 파일 경로와 SHA256을 기록했습니다.

## 포스터에서 먼저 사용할 화면

1. 목적별 추천을 소개할 때는 `01_포스터_핵심화면/02_U-010_목적별_대여_조건.png`과 `03_나란히_배치한_화면/01_목적별_추천결과_장비와시설.png`를 함께 배치합니다.
2. 조회와 신청을 소개할 때는 `01_포스터_핵심화면/05_U-002-02_장비_조회_결과.png`와 `01_포스터_핵심화면/07_C-004_선택_목록.png`을 사용합니다. 시설 중심 설명에는 `01_포스터_핵심화면/06_U-005-02_시설_조회_결과.png`가 어울립니다.
3. 관리자 업무를 소개할 때는 `01_포스터_핵심화면/09_A-001_관리자_신청_관리.png`와 `03_나란히_배치한_화면/03_반납검수_구성품과확정.png`를 사용합니다. 추가 반환 관리도 강조하려면 같은 폴더의 네 번째 파일을 사용합니다.

Figma에서는 사용할 PNG를 캔버스로 드래그하고 가로세로 비율을 유지해 배치합니다. 미리보기는 파일 선택용이고 실제 포스터에는 개별 PNG 또는 나란히 배치한 PNG를 넣습니다.

## 추출 기준

원본은 `New-Era 화면설계서_20261026.pptx`와 `New-Era 화면설계서_20261027.pdf`입니다. 두 자료의 39쪽 구성과 화면 ID를 대조하고 PPT에 포함된 PNG 37개를 원래 바이트 그대로 추출했습니다. PDF에서 줄어든 이미지보다 PPT 원본이 큰 경우 PPT 해상도를 유지했습니다.

설계서의 제목·설명표·기능 번호는 별도 도형이므로 개별 PNG에는 포함되지 않습니다. 입력 영역과 확정 버튼이 따로 배치된 검수 화면은 원본에서도 분리된 이미지입니다. 나란히 배치한 파일은 이 두 영역을 함께 보기 위한 조합입니다.

이 자료는 2026년 10월 화면설계서에 수록된 화면이며, 화면 안의 날짜·신청 번호·계정 등은 원본의 시연 정보입니다. 최신 개발 화면을 설명할 때는 현재 구현과 해당 화면의 일치 여부를 확인합니다.
